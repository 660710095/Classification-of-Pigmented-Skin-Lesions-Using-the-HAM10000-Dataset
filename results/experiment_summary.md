# สรุปผลการทดลอง: ResNet-50 Baseline (1-Dense Layer) บนชุดข้อมูล HAM10000

เอกสารสรุปผลการทดลองการจำแนกรอยโรคผิวหนัง 7 คลาส (Skin Lesion Classification) ด้วยโมเดล **ResNet-50 Pretrained** บนชุดข้อมูล **HAM10000 (10,015 ภาพ)** แบ่งข้อมูลแบบ Stratified Group Split (70% Train / 15% Val / 15% Test) ตาม `lesion_id` เพื่อป้องกัน Data Leakage

---

## 1. รายละเอียดการตั้งค่าในการทดลองนี้ (Experiment Configurations)

ในการทดลองรอบนี้ ได้ปรับแต่งองค์ประกอบโครงสร้างโมเดลและพารามิเตอร์การฝึกสอนดังนี้:

| หมวดหมู่ | ตัวแปร / ไฮเปอร์พารามิเตอร์ | ค่าที่กำหนด | เหตุผลทางเทคนิค |
|---|---|---|---|
| **สถาปัตยกรรม** | Backbone Model | `ResNet-50` (Pretrained ImageNet) | สกัด Feature ภาพทั่วไปที่มีประสิทธิภาพสูง |
| **โครงสร้างส่วนหัว** | Classification Head (`model.fc`) | **1 Dense Layer** (`hidden_dim = None`) | `Dropout(0.3) -> Linear(2048, 7)` ลดพารามิเตอร์และลดโอกาส Overfitting |
| **Backbone Training** | Freeze Backbone | `False` (Fine-tune ทั้งตัว) | ปรับปรุง Weight ของ Convolutional layers ให้เข้ากับภาพรอยโรคผิวหนัง |
| **Optimizer** | Optimizer | `AdamW` (Weight Decay = `1e-4`) | ป้องกันค่าน้ำหนักขยายใหญ่เกินไป (L2 Regularization) |
| **อัตราการเรียนรู้** | Differential LR | `backbone_lr = 1e-5`, `head_lr = 1e-4` | Backbone ใช้ LR ต่ำกว่า 10 เท่าเพื่อถนอม Feature ImageNet เดิม |
| **รอบการฝึกสอน** | Epochs & Batch Size | `15 Epochs`, `Batch Size = 64` | เหมาะสมกับขนาดหน่วยความจำ VRAM (24GB) |
| **การจัดการ Imbalance** | Loss Function & Class Weights | `CrossEntropyLoss` + `Inverse Frequency Weights` | ถ่วงน้ำหนักคลาสส่วนน้อย (`df=12.5`, `vasc=10.0`, `nv=0.21`) |
| **Regularization** | Label Smoothing | `0.1` | ป้องกันโมเดล Overconfident ในเคสที่รอยโรคคาบเกี่ยวกัน |
| **Data Augmentation** | On-the-fly Transforms | Flips, Rotation 180°, ResizedCrop, ColorJitter | จำลองสภาพแสง กล้อง และมุมมองที่แตกต่างกันในคลินิก |

## 3. วิเคราะห์ผลลัพธ์: อะไรแม่นอยู่ (Strengths)

1. **การตรวจจับกลุ่มโรคร้ายแรงและมะเร็งทำได้ดีเยี่ยม (High Clinical Recall)**:
   * **`akiec` (Recall 85.71%)**: ตรวจจับระยะก่อนมะเร็งได้ 42 จาก 49 ภาพ
   * **`bcc` (Recall 79.49%, F1 = 0.6526)**: ตรวจจับมะเร็งผิวหนังชนิดพบบ่อยได้เกือบ 80%
   * **`vasc` (Recall 90.48%)**: ตรวจจับรอยโรคหลอดเลือดได้ 19 จาก 21 ภาพ
   * **`mel` (Recall 55.95%)**: มะเร็งเมลาโนมาที่มีอันตรายถึงชีวิต ตรวจจับได้เกินครึ่งหนึ่งของเคสทดสอบ
   > *ในทางการแพทย์ (Medical AI) ค่า Recall สูงเป็นสิ่งสำคัญอันดับแรก เพราะป้องกันไม่ให้คนไข้มะเร็งถูกคัดกรองหลุดรอด (False Negative ต่ำ)*

2. **ความเชื่อมั่นของไฝปกติ (`nv`) สูงมาก**:
   * ค่า **Precision ของ `nv` อยู่ที่ 97.24%** หมายความว่า หากโมเดลทำนายว่าเป็นไฝธรรมดา จะมีความถูกต้องสูงถึง 97% แทบไม่มีกรณีทายผิดว่าเป็นไฝแล้วความจริงเป็นมะเร็ง

## 4. วิเคราะห์ผลลัพธ์: อะไรด้อยไปและสาเหตุ (Weaknesses & Root Causes)

1. **Precision ของคลาสหายากต่ำมาก (Severe False Positives)**:
   * โดยเฉพาะ **`df` (Precision เพียง 3.91%)** และ **`vasc` (Precision 26.03%)**
   * **สาเหตุหลัก**: เกิดจาก **Extreme Class Weights** จากสูตร Inverse Frequency ซึ่งให้น้ำหนักคลาส `df` สูงถึง **12.51** และ `vasc` สูงถึง **10.01** ขณะที่ `nv` ได้น้ำหนักเพียง **0.21** (ต่างกันเกือบ **60 เท่า**)
   * ทำให้เมื่อโมเดลไม่แน่ใจ จะเลือกทำนายเป็น `df` หรือ `vasc` เพื่อเลี่ยงการถูกทำโทษ Loss อย่างรุนแรง ส่งผลให้ภาพไฝปกติหลายร้อยภาพถูกทายผิดเป็น `df`
2. **Recall ของไฝปกติ (`nv`) ลดลงเหลือ 52.64%**:
   * เพราะตัวอย่าง `nv` ถูก "แย่งทำนาย" ไปเป็นคลาสอื่น ทำให้ความแม่นยำรวมของทั้งระบบ (Overall Accuracy) หล่นมาอยู่ที่ **56.09%**
3. **ระยะเวลาการเทรนสั้นไป (ยังไม่ลู่เข้าสมบูรณ์)**:
   * ดูกราฟจาก [`results/resnet50_loss_accuracy.png`](resnet50_loss_accuracy.png) พบว่า Train Loss ยังคงลดลงต่อเนื่อง (จาก 2.58 เหลือ 1.85) แสดงว่าโมเดลยังคงเรียนรู้ฟีเจอร์ได้อีก หากเพิ่มรอบ Epochs

## 5. สิ่งที่คาดว่าน่าลองปรับในรอบถัดไป (Proposed Improvements)

| ลำดับ | สิ่งที่ควรปรับปรุง | แนวทางปฏิบัติ | ผลลัพธ์ที่คาดหวัง |
|:---:|---|---|---|
| **1** | **ปรับ Class Weights ให้นุ่มนวลลง** | เปลี่ยนจากการคูณผกผันตรงๆ เป็น **Square-Root Inverse Frequency** เช่น `sqrt(max / count)` หรือคุมเพดานไม่เกิน 3–4 เท่า | ดึง Precision ของ `df/vasc` สูงขึ้น และดึง Recall ของ `nv` กลับมาที่ 80%+ ความแม่นยำรวมจะพุ่งทะลุ 75% |
| **2** | **สลับมาใช้ WeightedRandomSampler** | เปิด `use_weighted_sampler: True` และปิด `use_class_weights` ใน Cell 1 | กระจายสัดส่วนการมองเห็นของแต่ละคลาสในแต่ละ Batch อย่างเท่าเทียม โดยไม่ต้องปรับแก้ Loss function |
| **3** | **เพิ่มจำนวน Epochs เป็น 25–30 รอบ** | ปรับ `TRAIN_CONFIG['epochs'] = 30` | ให้เวลา Backbone และ Classification Head ปรับจูนรายละเอียดรอยโรคให้สมบูรณ์ขึ้น |
| **4** | **ปรับ Backbone Learning Rate** | เพิ่ม `backbone_lr` จาก `1e-5` เป็น `3e-5` | ช่วยให้ชั้น Convolutional ปรับตัวเข้ากับลักษณะ Texture ผิวหนังได้เร็วยิ่งขึ้น |
| **5** | **ทดลองใช้ Focal Loss** | นำ Focal Loss เข้ามาแทน CrossEntropyLoss | โฟกัสเฉพาะเคสภาพที่จำแนกยาก (Hard Examples) แทนการถ่วงน้ำหนักภาพทุกภาพเท่ากัน |
| **6** | **เปรียบเทียบกับ 2 Dense Layers** | ลองปรับ `'hidden_dim': 512` หรือ `[1024, 512]` | ให้ส่วนหัวมีขีดความสามารถในการเรียนรู้ Pattern ซับซ้อน เพื่อแยกแยะรอยโรคสีเข้มระหว่าง `mel` vs `bkl` |

## 6. สรุปภาพรวมสำหรับรายงานและนำเสนอ (Executive Summary)

> การทดลองนี้แสดงให้เห็นว่า **ResNet-50 แบบ 1-Dense Layer สามารถจับฟีเจอร์ของโรคมะเร็งผิวหนังที่อันตรายได้อย่างมีนัยสำคัญ (Recall สูง 70% – 85%)** แต่มีข้อจำกัดด้านความสมดุลของคลาสเนื่องจากน้ำหนัก Loss ที่รุนแรงเกินไป การปรับลดความตึงของ Class Weights และเพิ่มรอบการเทรนเป็น 30 รอบในการทดลองรอบถัดไป จะเป็นกุญแจสำคัญในการดันความแม่นยำรวม (Accuracy) ให้ขึ้นไปสู่ระดับ **80%+**
