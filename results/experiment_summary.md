# สรุปผลการทดลอง: ResNet-50 บนชุดข้อมูล HAM10000 (เปรียบเทียบ Exp 1 vs Exp 2)

เอกสารสรุปผลการทดลองการจำแนกรอยโรคผิวหนัง 7 คลาส (Skin Lesion Classification) ด้วยโมเดล **ResNet-50** บนชุดข้อมูล **HAM10000 (10,015 ภาพ)** แบ่งข้อมูลแบบ Stratified Group Split (70% Train / 15% Val / 15% Test) ตาม `lesion_id` เพื่อป้องกัน Data Leakage

---

## 1. ตารางเปรียบเทียบการตั้งค่าพารามิเตอร์ (Experiment Configurations)

| การตั้งค่า / ไฮเปอร์พารามิเตอร์ | การทดลองที่ 1 (Baseline 1-Dense) | การทดลองที่ 2 (Proposed 3-Dense Head) | เหตุผลทางเทคนิคในการปรับปรุง |
|---|---|---|---|
| **Backbone Model** | ResNet-50 (Pretrained ImageNet) | ResNet-50 (Pretrained ImageNet) | โครงสร้างหลักมาตรฐานคงเดิมเพื่อเปรียบเทียบแฟร์ |
| **Classification Head** | **1 ชั้น**: `Linear(2048 -> 7)` | **3 ชั้น**: `Linear(2048->1024) -> Linear(1024->512) -> Linear(512->7)` + BatchNorm + ReLU + Dropout(0.3) | เพิ่ม Non-linear Layer ลดมิติแบบขั้นบันได ช่วยจำแนกขอบเขตโรคซับซ้อน |
| **จำนวนรอบ (Epochs)** | 15 Epochs | **30 Epochs** | ให้เวลาโครงข่ายเรียนรู้และ Fine-tune ฟีเจอร์ได้เต็มที่ |
| **Backbone Learning Rate** | `1e-5` | **`3e-5`** | เร่งการปรับค่าน้ำหนัก Convolution ให้เข้ากับภาพรอยโรคเร็วขึ้น |
| **Head Learning Rate** | `1e-4` | `1e-4` | คงไว้ที่ระดับมาตรฐานสำหรับ Dense Classifier |
| **การแก้ปัญหา Class Imbalance** | Inverse Frequency Weights ใน Loss (ต่างกัน 60 เท่า) | **`WeightedRandomSampler`** | สุ่ม Batch ให้มีสัดส่วนคลาสสมดุลเท่าเทียมกัน ไม่บิดเบือน Gradient ใน Loss |
| **Regularization** | Dropout 0.3, Label Smoothing 0.1 | Dropout 0.3, Label Smoothing 0.1 | ควบคุมไม่ให้โมเดล Overfitting |
| **Batch Size & Precision** | 64, bfloat16 AMP | 64, bfloat16 AMP | ประหยัด VRAM และเทรนได้รวดเร็ว |

## 4. วิเคราะห์การเกิด Underfitting / Overfitting ของทั้งสองการทดลอง

### 4.1 การทดลองที่ 1 (Exp 1: Baseline) ➔ **เกิด "Underfitting" ชัดเจน**
1. **Train Accuracy บนข้อมูลฝึกตัวเองต่ำมาก**: ทำได้เพียง **45.6%** แสดงว่าโมเดลยังไม่สามารถเรียนรู้ลักษณะร่วมของภาพได้ดีพอ
2. **Loss ยังลดลงไม่สุด**: กราฟ Train Loss ยังมีทิศทางดิ่งลงอย่างต่อเนื่อง (2.58 เหลือ 1.85) แสดงว่ายังไม่ลู่เข้า (ยังเรียนรู้ได้อีกหากไม่ถูกตัดจบที่ 15 รอบ)
3. **โครงสร้างตื้นเกินไป**: การบีบมิติจาก 2048 พิกเซลลงเหลือ 7 คลาสทันที (Linear 1 ชั้น) ขาด Non-linear capacity ในการแยกโรคที่สีผิวหรือลักษณะใกล้เคียงกัน

### 4.2 การทดลองที่ 2 (Exp 2: Proposed) ➔ **เป็น "Optimal Fit" สู่ "Slight Overfitting ช่วงปลาย"**
1. **Generalization สูงมาก (ไม่จำข้อสอบ)**:
   * Validation Accuracy อยู่ที่ **84.36%** และเมื่อทดสอบบน Test Set ที่ไม่เคยเห็นมาก่อนได้ถึง **83.10%** (คะแนนใกล้เคียงกันมาก แสดงว่าโมเดลเข้าใจธรรมชาติของโรคจริง)
2. **การเรียนรู้ช่วง Epoch 1–25 เป็นจุดสมดุลที่ดีที่สุด**:
   * Val Loss ลดลงขนานไปกับ Train Loss (จาก 1.11 เหลือ **0.80**) และคะแนน Val F1 ไต่ถึงจุดสูงสุดที่ **75.59%**
3. **เริ่มมี Overfitting เล็กน้อยใน Epoch 26–30**:
   * Train Accuracy พุ่งไปถึง 98% ขณะที่ Val Accuracy ทรงตัวอยู่ที่ 84%
4. **ประโยชน์ของ Best-Checkpoint**:
   * ระบบอัตโนมัติเลือกบันทึกน้ำหนักที่ **Epoch 25** (จุดที่ Val Macro-F1 พีคสุด) ทำให้โมเดลที่นำมาทดสอบบน Test Set รอดพ้นจาก Overfitting ช่วงปลายได้อย่างสมบูรณ์

## 5. สรุปความเปลี่ยนแปลงและสิ่งที่ได้หลังจากปรับพารามิเตอร์ (What Changed & Gained)

1. **กอบกู้ Precision ของคลาสหายากสำเร็จเด็ดขาด**:
   * คลาส `df` ในรอบแรกมี Precision เพียง **3.91%** (ทายผิดมั่วซั่วไปเกือบ 400 ภาพ) ในรอบที่ 2 พุ่งกระฉูดขึ้นเป็น **76.47%** และ `vasc` พุ่งขึ้นเป็น **90.00%** เนื่องจากการใช้ `WeightedRandomSampler` แทนการคูณน้ำหนัก Loss ที่รุนแรง
2. **การฟื้นตัวของคลาสหลัก (ไฝปกติ `nv`)**:
   * ค่า Recall ของ `nv` ดีดตัวจาก 52.64% ขึ้นมาเป็น **91.44%** ทำให้ภาพไฝปกติไม่ถูกแย่งทำนายมั่ว เป็นปัจจัยหลักที่ส่งให้ **Overall Accuracy พุ่งขึ้นถึง +27% (จาก 56.09% ➔ 83.10%)**
3. **การจำแนกโรคมะเร็งอันตรายคมชัดขึ้น**:
   * F1-Score ของมะเร็งผิวหนัง `bcc` เพิ่มขึ้นเป็น **0.7294** และระยะก่อนมะเร็ง `akiec` เพิ่มเป็น **0.6923**
4. **ความเสถียรของโมเดล**:
   * โครงสร้าง Dense 3 ชั้น (`[1024, 512]`) ร่วมกับ `BatchNorm1d` ช่วยให้การกระจายตัวของค่า Activation สม่ำเสมอ ทำให้โมเดลเทรนได้อย่างราบรื่นและไม่เกิด Gradient Vanishing

## 6. แนวทางการปรับแต่งเพื่อผลักดันความแม่นยำให้สูงขึ้นในอนาคต (Actionable Next Steps)

หากต้องการผลักดันความแม่นยำรวมให้ทะลุระดับ **85% – 88%** สามารถทำได้ดังนี้:

1. **เพิ่มความละเอียดภาพ (Image Resolution `224` ➔ `256` หรือ `300`)**:
   * ภาพผิวหนังมีรายละเอียดเม็ดสีขนาดเล็ก (Pigment Networks, Globules, Blotches) การเพิ่มขนาดภาพจะช่วยให้โครงข่ายแยกความต่างระหว่าง `mel` (มะเร็งเมลาโนมา) กับ `bkl` (กระเนื้อ) ได้เด็ดขาดขึ้น
2. **เปิดใช้ Test-Time Augmentation (TTA)**:
   * ในขั้นตอน Inference ให้ส่งภาพต้นฉบับ + ภาพพลิกแนวนอน + ภาพพลิกแนวตั้ง เข้าไปทำนายพร้อมกันแล้วเฉลี่ย Softmax Probability ช่วยเพิ่ม Accuracy ได้ฟรี **1.5% – 2.5%** โดยไม่ต้องเทรนใหม่
3. **ปรับลด Label Smoothing เป็น `0.05`**:
   * ในโมเดลที่แม่นยำระดับ 83%+ การลด Smoothing จาก 0.1 เหลือ 0.05 จะช่วยให้โมเดลมีความเด็ดขาดในการทำนายคลาสที่มั่นใจสูงมากยิ่งขึ้น
4. **ทดลองใช้ Backbone สถาปัตยกรรมใหม่ (เช่น EfficientNet-B3 หรือ ConvNeXt-Tiny)**:
   * นำมาเปรียบเทียบในโปรเจกต์คู่กับ ResNet-50 เพื่อวิเคราะห์ประสิทธิภาพของสถาปัตยกรรมต่างยุคสมัย
