# Classification of Pigmented Skin Lesions Using the HAM10000 Dataset

This project develops deep learning models to classify seven types of pigmented skin lesions from dermatoscopic images in the HAM10000 dataset (10,015 images). We compare a custom CNN against three transfer learning models (ResNet50, DenseNet121, EfficientNet-B0), address severe class imbalance, and use Grad-CAM to interpret model predictions.

* **GitHub Repository**: [`https://github.com/660710095/Classification-of-Pigmented-Skin-Lesions-Using-the-HAM10000-Dataset`](https://github.com/660710095/Classification-of-Pigmented-Skin-Lesions-Using-the-HAM10000-Dataset)

## 4. Dataset Splitting & Zero-Leakage Guarantee

Skin lesions can have multiple dermatoscopic images taken over time or from different angles. To prevent data leakage and inflated validation metrics, **images of the same `lesion_id` must never cross splits**.

Generate the 70/15/15 train/val/test splits using 20-fold `StratifiedGroupKFold`:
```bash
python scripts/make_splits.py
```

### Verification & Leakage Checks:
- **Total Images**: Exactly 10,015.
- **Lesion Leakage**: 0 overlap between Train & Val, Train & Test, and Val & Test.
- **Split Proportions**:
  - `train`: 7,009 images (~69.99%)
  - `val`: 1,503 images (~15.01%)
  - `test`: 1,503 images (~15.01%)
- Output saved to `splits/splits.csv` with columns: `image_id, lesion_id, dx, split`.

## 5. Teammate Model Development (Decoupled Registry)

To avoid git merge conflicts when 4 teammates work on different architectures simultaneously, **each model lives in its own file in `src/models/<name>.py` and self-registers**. Teammates never need to edit `src/models/__init__.py`.

### Example: Adding ResNet-50
Create `src/models/resnet50.py`:
```python
import torch.nn as nn
import torchvision.models as models
from src.models import register_model

@register_model("resnet50")
def build_resnet50(num_classes: int = 7, pretrained: bool = True, **kwargs) -> nn.Module:
    weights = models.ResNet50_Weights.DEFAULT if pretrained else None
    model = models.resnet50(weights=weights, **kwargs)
    model.fc = nn.Linear(model.fc.in_features, num_classes)
    return model
```

### Example: Instantiating Models in Training Scripts / Jupyter
```python
from src.models import get_model, list_models

print("Available models:", list_models())
model = get_model("resnet50", num_classes=7, pretrained=True).cuda()
```

## 6. Training Pipeline & Hardware Optimization

The workspace runs on an **NVIDIA RTX PRO 6000 GPU (24 GB VRAM)** shared across teammates.

### Key Features:
1. **Mixed Precision (`bf16`)**:
   Uses native hardware `bfloat16` via `torch.autocast(device_type="cuda", dtype=torch.bfloat16)`.
2. **Optimized DataLoader**:
   Configured with `num_workers: 4`, `pin_memory: true`, and `persistent_workers: true`.
3. **Severe Class Imbalance Handling**:
   - `get_class_weights()`: Computes balanced inverse frequency weights for `nn.CrossEntropyLoss(weight=weights)`.
   - `get_weighted_sampler()`: PyTorch `WeightedRandomSampler` for balanced mini-batches.
4. **Optional In-RAM Caching (`cache_in_ram: true`)**:
   Pre-resizes images once to `(img_size, img_size)` and stores them as compact `uint8` tensors in system RAM (~1.05 GB for train). Transforms and random augmentations are still applied dynamically on-the-fly each epoch!

### Minimal Training Example (Run from Root):
```python
import torch
import torch.nn as nn
from torch.utils.data import DataLoader

from src.utils import print_env_info, set_seed, load_config, get_amp_context
from src.augment import get_train_transform, get_val_transform
from src.dataset import HAM10000Dataset, get_class_weights
from src.models import get_model

# 1. Hardware & Seeding
print_env_info()
cfg = load_config("configs/config.yaml")
set_seed(cfg["seed"])
device = torch.device("cuda" if torch.cuda.is_available() else "cpu")

# 2. Datasets & Loaders
train_ds = HAM10000Dataset(
    splits_csv=cfg["splits_file"],
    split="train",
    data_dir=cfg["data_dir"],
    transform=get_train_transform(cfg["img_size"]),
    cache_in_ram=cfg["cache_in_ram"]
)
val_ds = HAM10000Dataset(
    splits_csv=cfg["splits_file"],
    split="val",
    data_dir=cfg["data_dir"],
    transform=get_val_transform(cfg["img_size"]),
    cache_in_ram=cfg["cache_in_ram"]
)

train_loader = DataLoader(
    train_ds,
    batch_size=cfg["batch_size"],
    shuffle=True,
    num_workers=cfg["num_workers"],
    pin_memory=cfg["pin_memory"],
    persistent_workers=cfg["persistent_workers"]
)

# 3. Model, Loss, Optimizer
model = get_model("resnet50", num_classes=7, pretrained=True).to(device)
class_weights = get_class_weights(cfg["splits_file"]).to(device)
criterion = nn.CrossEntropyLoss(weight=class_weights)
optimizer = torch.optim.AdamW(model.parameters(), lr=cfg["lr"], weight_decay=cfg["weight_decay"])

# 4. Training Step with AMP (bf16)
for images, labels in train_loader:
    images, labels = images.to(device, non_blocking=True), labels.to(device, non_blocking=True)
    optimizer.zero_grad(set_to_none=True)
    with get_amp_context(use_amp=cfg["use_amp"]):
        outputs = model(images)
        loss = criterion(outputs, labels)
    loss.backward()
    optimizer.step()
```

```
              เทรน (เงื่อนไขเดียวกัน) -> ประเมินบน test -> Grad-CAM -> รายงาน
```

### 8.3 กฎสำคัญประจำโปรเจค (Team Rules)

1. **แบ่งข้อมูลก่อน แล้วค่อย augment** เฉพาะชุด train และ augment แบบ on-the-fly ไม่สร้างไฟล์รูปเพิ่ม
2. **ห้ามแก้ `splits.csv`, `augment.py`, `dataset.py` ในแต่ละ branch** ถ้าต้องแก้ ให้แจ้งทีมและแก้ใน main ที่เดียว
3. **ห้ามใช้ test set** ในการเทรน ทำ early stopping หรือปรับ hyperparameter
4. **เงื่อนไขเทรนเดียวกันทุกโมเดล** เพื่อให้เปรียบเทียบได้ยุติธรรม ขนาดรูปอื่นให้แยกเป็นการทดลองเพิ่มเติมและเขียนกำกับ
5. **ห้าม commit รูปภาพและ checkpoint** เข้า git
6. **ใช้ GPU ร่วมกัน (VRAM 24 GB)** ควรตกลงเวลาเทรนไม่ให้ซ้อนกัน
